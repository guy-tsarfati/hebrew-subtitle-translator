# CueIvrit v0.1.0 - first public preview

An open-source agent skill for English-to-Hebrew SRT translation, repair, and selective polishing. The scripts prepare, validate, build, and audit subtitles. An AI assistant or human translator writes the Hebrew and reviews every cue.

## Included

- Original cue IDs and source timing, UTF-8 BOM, and the existing Hebrew RTL output profile.
- Conservative, source-bound SDH and external subtitle-credit cleanup decisions.
- Character gender, speaker/addressee, and recurring terminology guidance.
- Full bilingual editorial-review helpers and synthetic regression checks.
- A 26-cue Sintel example with separate Creative Commons attribution.
- CueIvrit branding, installation guide, Wiki, support and contribution routes, and feedback forms.

## Install and try

Prerequisites: Node.js 22.20.0+ and npm for the tested installer, Python 3.10+ for the helpers, and an assistant supporting agent skills.

```bash
npx skills@1.7.1 add guy-tsarfati/hebrew-subtitle-translator --skill hebrew-subtitle-translator --agent codex --yes --copy
```

This is a project installation and follows the repository's default branch. Pinning the CLI does not pin the skill revision. To use exactly this release, download its source ZIP and install the complete skill directory manually.

See [INSTALLATION.md](../../INSTALLATION.md), [the Sintel example](../../examples/README.md), and [the Wiki](https://github.com/guy-tsarfati/hebrew-subtitle-translator/wiki).

## Verified and still experimental

Clean CLI installation for the Codex target included all tested bundled resources. Pipeline regressions and all 10 quality tests passed in the fresh checkout and installed copy. CI passed on Python 3.10 and 3.12. The 26-cue Sintel rebuild passed audit and matched the committed SRT byte for byte.

All 26 Hebrew cues were inspected on rendered film frames with FFmpeg/libass. See [VISUAL_CHECK.md](../../VISUAL_CHECK.md) for the exact configuration and the source/embedded-track difference in cue 1. This does not establish native-player compatibility or full audiovisual playback verification.

A complete translation task inside the installed assistant, native player playback, and other agent/OS combinations remain unverified. Scripts do not translate, transcribe video, retime another release, or guarantee semantic accuracy or universal player support. This is a pre-release for trial use and feedback.

The skill, code, and documentation are MIT licensed. Sintel dialogue examples and any QA contact sheets carry separate Creative Commons attribution. The full film is not bundled.

Please report installation, Hebrew/context, and player-display feedback through the [trial feedback form](https://github.com/guy-tsarfati/hebrew-subtitle-translator/issues/new/choose), using short synthetic or permission-cleared examples.
