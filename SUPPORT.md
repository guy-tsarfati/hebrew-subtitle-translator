# Getting help with CueIvrit

Start with the [Getting Started guide](https://github.com/guy-tsarfati/hebrew-subtitle-translator/wiki/Getting-Started) and the [Sintel example](examples/README.md).

## Bugs, questions, and feedback

Use [GitHub Issues](https://github.com/guy-tsarfati/hebrew-subtitle-translator/issues). Choose the bug or feature form when it fits. For a usage question, describe what you tried and where the instructions became unclear.

Include:
- The release or commit you used, your AI assistant, operating system, and Python version.
- The command or prompt, expected result, and actual result.
- Relevant error text and a small synthetic or permission-cleared example.
- For display problems, the player and version, plus a screenshot without private content.
- For translation feedback, the English meaning, Hebrew proposal, and speaker/addressee context.

Do not post secrets, private media, or complete subtitle files without permission. A structural PASS does not establish translation accuracy or correct display in every player.

## Private reports

Report security vulnerabilities through [SECURITY.md](SECURITY.md). Report conduct concerns privately as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

The maintainer is Guy Tsarfati. For project matters that require private contact, use guy@tsarfati.com. Public issues are preferred for ordinary support so other users can benefit.

Community support is provided as time permits. No response timeframe is guaranteed.
