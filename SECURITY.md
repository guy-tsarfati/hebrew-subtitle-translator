# Security policy

## Reporting a vulnerability

Please do not disclose an exploitable issue in a public GitHub issue. Use GitHub's **Report a vulnerability** option in this repository's [Security advisories](https://github.com/guy-tsarfati/hebrew-subtitle-translator/security/advisories) to send a private report. Include the affected version or commit, steps to reproduce, and the potential impact. Avoid including private subtitle files or secrets.

The maintainer will review the report and coordinate a fix and disclosure when applicable. No response or fix timeframe is guaranteed.

For ordinary behavior bugs, translation errors, or documentation suggestions, use [Issues](https://github.com/guy-tsarfati/hebrew-subtitle-translator/issues).
